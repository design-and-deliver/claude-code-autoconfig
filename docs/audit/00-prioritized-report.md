## The four cross-cutting failure classes

Most of the ~86 findings are instances of four repeating classes:

1. **Hand-copied lists that drift.** `DEV_ONLY_FILES` (bin/cli.js:751) is hand-mirrored in
   `sync-docs.js:37` (drifted → live bug: shipped docs advertise 5 dev-only features) and in
   `validate-cca-install.md:71` (drifted → 4 false "MISSING CMD" errors for every user). Same
   class: `AUTOCONFIG_FILES`, `MANAGED_HOOKS`, the hand-maintained `npm test` chain, the README
   file tree. Fix pattern: single-source or test-pin every list.
2. **Prose that is actually API.** Machine-read literals that look like harmless wording: the
   `--analyze` digest headers, the `@applied` block, the `AUTO-GENERATED BY /autoconfig` marker,
   hook `command` strings (merge dedups by exact string), command-file phrases that tests grep.
   A weak model rewording "prose" breaks running systems.
3. **Designed silence hiding regressions.** 131 `catch(_){}` blocks, hooks that exit 0 on every
   failure, tests that skip silently off the dev box, source-string tests that pass vacuously
   (the box test finds 0 boxes and passes). "It didn't error" proves nothing anywhere.
4. **Parallel implementations.** The FEEDBACK→Discoveries migration exists in 4 live places; the
   curl installers are a drifted parallel of bin/cli.js that produces broken installs; `archive/`
   and `internal/` hold byte-identical or stale twins of live shipped files.

## Standing trap warnings (condensed)

Full inventory: `03-hazards-and-god-files.md` (T1–T17, C1–C9). The five that must precede any edit:

1. **Never rename fields in any serialized user-project file** (`.autoconfig-*.json`,
   `cca.config.json`, `.titles/*.history.jsonl`, `.token-guard/*`) — real users, additive-only.
2. **Never trust package.json `files` to gate installs** — `DEV_ONLY_FILES` (bin/cli.js:751) is
   the gate, and its one-line single-quoted literal is itself a test interface.
3. **Never edit generated or non-canonical copies** — CHANGELOG.md, autoconfig.docs.html, any
   terminal-title.js outside `.claude/hooks/terminal-title.js`.
4. **Never reorder bin/cli.js top-level flow or extract its box/DEV_ONLY literals** — tests
   regex the source; install correctness is statement order.
5. **Never reword machine-read strings that look like prose** — digest headers, the
   `AUTO-GENERATED BY /autoconfig` marker, the `@applied` block, `name|event` glyph files, hook
   `command` strings in settings.json.

## What is deliberately NOT being "fixed"

Verified by-design; flagging them as problems would itself be a lie:

- `terminal-title.js` monolith — single-file by contract (fleet sync + parity test require it).
- The arcade/status-beeps alias pairs — deliberate deprecated aliases, test-guarded.
- `arcade-beeps.js` keeping its filename — installed settings.json files point at it literally.
- Legacy compat paths (`@screenshotDir` handling needs a *fix*, not deletion; deprecated alias
  shipping; recover.json flat shape while `ccr` remains published).
